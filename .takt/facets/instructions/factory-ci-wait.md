Report Directory の `publish.md` から PR 番号とプッシュした先頭のコミットを読み、その PR の CI の結果を見届けてください。ファイルは変えません。

**手順:**

1. `gh pr view <番号> --json headRefOid,isDraft` で、PR の先頭のコミットが `publish.md` のものと同じことを確かめる。違えば待たずに「CI の結果を確かめられなかった」を選ぶ
2. チェックが登録されるのを待つ。`gh pr checks <番号>` が「チェックがない」と返す間は、30 秒ごとに最大 10 分まで確かめ直す
3. すべてのチェックが終わるまで待つ。シェルの1回のコマンドには時間の上限があるので、`timeout 540 gh pr checks <番号> --watch --interval 30` を、チェックが終わるまで繰り返す(終了コード 124 は時間切れで、まだ終わっていない)。待ち始めてから 60 分を超えたら待つのをやめる
4. 結果を読む
   - 必須チェック: `gh pr checks <番号> --required`
   - すべてのチェック: `gh pr checks <番号> --json name,state,bucket,link,workflow`
5. 判定する
   - 必須チェックがすべて成功: CI が成功。必須でないチェックの失敗(mutation など)は、結果に書くだけにする
   - 必須チェックに失敗が1つでもある: CI が失敗。失敗したチェックの名前とリンクを結果に書く
   - チェックが登録されない、待つ時間を超えた、`gh` が失敗し続けた: CI の結果を確かめられなかった
6. `gh pr view <番号> --json isDraft` で、PR が Draft のままであることを結果に書く

CI を再実行しない(CI の承認は人の介入)。マージ・Ready 化はしない。
