この工程の検証の差し戻しを3回直しても、4回目の検証でまだ指摘が残っています(差し戻しの上限)。残った指摘を Issue にコメントして、この実行を止めてください。成果物は直さず、コミット・プッシュ・PR の作成・ラベルの変更もしません。

**手順:**

1. Report Directory の `triage.md` で Issue 番号と工程を読み、その工程の検証のレポート(`knowledge-review.md`・`requirements-review.md`・`spec-review.md`・`code-review.md` のうち、その工程のもの)の最新の指摘を読む
2. コメントを `$TMPDIR` のファイルに日本語で書き、`gh issue comment <n> --body-file <ファイル>` で出す
   - どの工程か、takt の中の検証の差し戻しを3回直しても4回目の検証で指摘が残り、上限に達して止めたこと
   - 残った指摘の表(対象・場所・内容・根拠)。検証のレポートから写し、言い換えで中身を変えない
   - ブランチ名と、プッシュしていないこと(既に PR があるときは、その PR は前の公開のままであること)
   - 人に決めてほしいこと(Yes/No か選択肢)。例: 指摘のどれを受け入れるか、上流(ナレッジ・要件・仕様・工場)のどこを直すか
   - 閉じるキーワードと `#番号` を続けて書かない。`/intervention` を書かない
3. コメントの URL を結果に書く
