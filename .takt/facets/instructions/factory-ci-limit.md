CI の失敗を3回直しても、4回目の CI がまだ失敗しています(CI の手直しの上限)。失敗の内容を Issue にコメントして、この実行を止めてください。成果物は直さず、コミット・プッシュ・ラベルの変更もしません。

**手順:**

1. Report Directory の `triage.md`(Issue 番号・工程)、`publish.md`(PR 番号)、`ci-wait.md`(最新の CI の結果)を読み、最新の失敗のログを `gh run view <run-id> --log-failed` で確かめる
2. コメントを `$TMPDIR` のファイルに日本語で書き、`gh issue comment <n> --body-file <ファイル>` で出す
   - どの工程の PR(番号)か、CI の失敗を3回直しても失敗が続き、上限に達して止めたこと
   - 失敗している必須チェックごとに、名前・リンク・エラーの要点(メッセージ、ファイルと行、失敗したテスト)
   - PR は Draft のまま残っていること
   - 人に決めてほしいこと(Yes/No か選択肢)。例: CI の再実行や例外の判断をするか、上流のどこを直すか
   - 閉じるキーワードと `#番号` を続けて書かない。`/intervention` を書かない
3. コメントの URL を結果に書く
