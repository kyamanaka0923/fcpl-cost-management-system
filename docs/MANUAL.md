# 総合原価管理システム 操作マニュアル

このマニュアルでは、システムの基本的な業務フローを

1. **計画策定**(部・課・案件の登録 → 半期予算の作成と承認)
2. **実績入力**(区分ごとの実績計上)
3. **計画変更**(半期途中の見直しによる予算の改定)

の順に説明します。最後に部の予実サマリと分析画面(差異分析・損益)の見方をまとめます。

---

## 0. 事前準備

### 起動

```bash
# Docker の場合
docker compose up backend frontend

# ローカルに SDK がある場合
cd backend && dotnet run --project src/CostManagement.WebApi   # API (localhost:5100)
cd frontend && npm install && npm run dev                      # 画面 (localhost:5173)
```

ブラウザで `http://localhost:5173` を開くと「課一覧」画面が表示されます。

### 基本の用語

| 用語 | 意味 |
|---|---|
| 部 | 課の上位組織。配下の課の予実を合計して把握する単位(部自体は予算を策定しない) |
| 課 | 予算策定の管理単位(部門)。必ず1つの部に属する |
| 半期 | 予算の策定単位となる期間。年度の**上期(4〜9月)/下期(10〜3月)**。表記は `2026-H1` / `2026-H2` |
| 案件 | 課に属する売上・コストの内訳単位(受託開発の案件など)。マスタとして登録する |
| 区分 | 予算の構成要素。**売上高・加工費・外注費**(案件別)と**期間費用**(費目別)の4つ |
| 費目 | 期間費用の内訳単位(人件費・ライセンス費など)。費目マスタで拡張できる |
| バージョン | 予算の版。承認すると編集不可になり、変更は改定版(新バージョン)として作成する |
| 部承認 | 部長が配下課の予算をまとめて確定する承認。配下課が全承認済みで可能。課の承認とは独立し取り消せる |

### 予算のステータス

| 状態 | 意味 | できること |
|---|---|---|
| 策定中(Draft) | 編集中のドラフト | 明細の追加・修正・削除、承認 |
| 承認済(Approved) | 有効な予算。予実比較の既定の基準 | 参照、改定版の作成 |
| 失効(Superseded) | 新しい版の承認により失効した旧版 | 参照、バージョン比較、改定の引継ぎ元 |

## 1. 計画策定

### 1-1. 部を登録する

1. トップの「部一覧」画面を開く
2. 「部の新規登録」フォームに **部コード**(例: `SALES`)、**部名**(例: 営業本部)を入力
3. **[登録]** をクリック → 一覧に追加されるので、部名のリンクから部詳細へ

> 部コードはシステム内で一意です。重複するとエラーになります。

### 1-2. 課を登録する

1. 部詳細の下部の「**課の登録**」フォームに **課コード**(例: `DEV-1`)、**課名**(例: 開発1課)を入力し **[登録]**
2. 「**課別の内訳**」表に課の行が増えるので、課名のリンクから課詳細へ

> 課コードはシステム内で一意です。課は必ずこの部に属します。

### 1-3. 対象半期を選ぶ

課詳細(および部詳細)の上部にある「**対象半期**」セレクタで、予算を策定する半期(例: 2026年度 上期)を
選びます。予算・実績・分析はすべてこの半期に紐付きます。

### 1-4. 半期予算(当初)を策定する

1. 課詳細の「**予算バージョン**」カードで、予算名(例: `当初予算`)を入力し **[ドラフト作成]**
   → 予算編集画面へ移動します
2. 「**案件別の売上高・加工費・外注費**」の表で、案件ごとに金額を入力する
   - まだ案件がなければ、表の下の「**案件を追加**」で案件コード(例: `PJ-001`)・
     案件名(例: 受託開発A)を入力し **[追加]** → 表に案件の行が増えます。
     **案件コードは課ごとに一意**です(別の課であれば同じコードを使えます)
   - 登録済みの案件は、案件名の横の **[編集]** からコード・名称を後から変更できます。
     案件は内部的に GUID で管理されるため、コード・名称を変えても既存の予算・実績の紐づけは保持されます
   - 各案件の行で、売上高・加工費・外注費の金額(**半期一括**、円)をセルに直接入力します。
     セルを離れると自動保存され、行末にその案件の**損益と粗利率(損益 ÷ 売上高)**が表示されます
   - 月ごとに計画したいときは各セルの **[月次入力]** を押し、ダイアログで月別金額を入力します。
     月次にした明細は半期一括入力が無効になり、**半期合計は月次の合計として自動算出**されます
     (画面の表示・集計は半期のまま。セルには「月次」バッジが付きます)
3. 「**期間費用**」の表でも同じように、費目(人件費・ライセンス費など)の行ごとに
   金額をセルに直接入力します(課共通の費用。セルを離れると自動保存)。
   費目は**システム共通のマスタ**から選びます。新しい費目が要るときは、画面右上のナビの
   「**費目マスタ**」画面で費目コード・費目名を登録してください(すべての部・課で共通)
   - 費目内をさらに細かく計画したいときは、その費目の行の「**明細を追加**」に明細名(例: `AWS`)と
     金額を入れて **[明細を追加]** します。明細名は自由入力で、費目の下に複数並びます
     (費目合計 = 明細の合計)。人件費など細分不要な費目は明細を使わず費目一括のままで構いません。
     各明細も **[月次入力]** に対応します。明細のある費目は行頭の **[▾]/[▸]** で明細を**折りたたみ/展開**できます
     (折りたたんでも費目の小計は表示されます)
   - **費目一括と明細は切り替えられます**。費目一括で金額を入力した後でも「明細を追加」すれば明細モードに
     切り替わります(このとき費目一括の金額は明細に置き換わります)。逆に、明細をすべて削除すると費目一括に戻せます
     (1費目内で費目一括と明細は混在できません)
4. 課の区分合計(売上高・加工費・外注費・期間費用)と計画損益(**粗利率**併記)は、
   明細の合計として画面上部のサマリタイルに自動反映されます(直接入力はできません)
5. 入力が済んだら **[この予算を承認する]** をクリック

> 承認のルール
> - 明細が1件もない予算は承認できません
> - 4区分をまとめて1つの予算として承認します(売上と原価を別々に承認する運用はありません)
> - 承認すると編集できなくなります(変更は「3. 計画変更」の手順で改定版を作成)
> - 策定中のドラフトは同一の課・半期に1つまでです。承認してから次の改定版を作成してください

## 2. 実績入力

実績は予算と独立して、発生の都度計上できます。
同じキー(区分 × 案件 または 費目)に**複数回計上でき、分析時に合算**されます
(例: 4月分・5月分を分けて計上)。

### 2-1. 実績を計上する

1. 課詳細 → **[実績入力]**
2. フォームに入力して **[計上]**
   - **区分**: 売上高 / 加工費 / 外注費 / 期間費用
   - **案件**(売上高・加工費・外注費のとき): プルダウンから選択。
     予算にない案件も計上でき、分析では「予定外」として表示されます
   - **費目**(期間費用のとき): プルダウンから選択
   - **明細**(期間費用で任意): 費目内の明細名。計画した明細があれば入力欄の候補から選べます。
     計画にない明細名でも計上でき、分析では「予定外」として表示されます(空欄なら費目一括の計上)
   - **月**(任意): 特定月の実績なら月を選択、半期まとめてなら「半期一括」。集計は半期で合算されます
   - **金額**: 金額(円)
   - **備考**(任意): 「検収1回目」など

### 2-2. 実績を訂正する

実績一覧の **[削除]** で取り消し、正しい内容で再計上してください。

## 3. 計画変更(予算の改定)

半期途中の見直しなどで計画が変わったら、承認済み予算を直接編集するのではなく
**改定版(新バージョン)を作成**します。旧版は履歴として残ります。

### 3-1. 改定版を作成する

1. 課詳細の「予算バージョン」カードで、予算名に改定の名称(例: `上期見直し`)を入力
2. **引継ぎ元バージョン** を選択(既定は最新承認版。任意の旧版からも引き継げます)
3. **[ドラフト作成]** → 引継ぎ元の**明細をすべてコピーした**ドラフトが新バージョンとして作成されます

### 3-2. 明細を修正して承認する

1. 編集画面で、変更のある明細だけ登録し直す(同じキーで登録すると上書き)。不要な明細は削除
2. **[この予算を承認する]** をクリック
3. 承認と同時に、同一の課・半期の**旧承認版は自動的に「失効」**になります(データは残り、参照・比較できます)

### 3-3. 改定内容を確認する(バージョン比較)

1. 課詳細 → **[予算バージョン比較]**
2. **基準バージョン**と**比較バージョン**を選択
3. 区分ごとの増減サマリと、案件・費目単位の増減明細が表示されます(例: 当初予算 vs 上期見直し)

> 差異分析は既定で「最新の承認済み予算」を基準にしますが、分析画面のバージョン選択で
> 旧版(当初予算など)を基準にした予実比較もできます。

## 4. 部の予算・予実サマリと分析画面の見方

### 部詳細(予算(計画)タブ / 予実サマリタブ)

部詳細を開くと、対象半期の**配下課の集計**が2つのタブで表示されます(既定は「予算(計画)」)。

**予算(計画)タブ** — 予算だけを課の画面と同じ粒度で参照します。

- 上部のタイル: 売上高予算・加工費予算・外注費予算・期間費用予算、計画損益(**粗利率**併記)
- 「**課ごとの予算比較**」: 各課の売上高・加工費・外注費・期間費用・計画損益・**粗利率**をグリッドで並べ、
  計画損益・粗利率を色分け(赤 = 赤字/低粗利)。どの課の損益が弱いかを一目で把握できます。
  課名のリンクから課詳細へドリルダウンでき、予算未策定の課は「**未策定**」と表示されます

**予実サマリタブ** — 予算と実績を突き合わせた差異を参照します。

- 上部のタイル: 売上高・総コストの予算/実績、損益予算・損益実績・損益差異
- 「**区分別の予実(部合計)**」: 売上高・加工費・外注費・期間費用ごとの予算・実績・差異
- 「**課別の内訳**」: 各課の売上・コスト・損益の予実。承認済み予算のない課は「**未策定**」と表示され、
  部合計には含まれません

「**部予算の承認**」はどちらのタブでも共通で表示されます。配下課の予算がすべて承認されると
「**部予算を承認する**」ボタンが押せます。承認すると承認済バッジと承認日時が表示され、
「**部承認を取り消す**」で未承認に戻せます。部の承認は課の承認とは独立しており、
部承認後に課を改定しても部承認は残ります(最新に合わせたいときは部を承認し直します)。

### 課の分析画面

課詳細 → **[予実差異分析・損益]**。2つのタブがあります。

### 予実差異タブ

- 差異 = **実績金額 − 予算金額**
- **コスト(加工費・外注費・期間費用)**: **正の値(赤)= 予算超過 = 不利差異**、負の値(緑)= 有利差異
- **売上高**: 符号がコストと逆で、**正の値(緑)= 売上超過 = 有利差異**、負の値(赤)= 未達
- 明細は「区分 × 案件(期間費用は費目)」の粒度で突き合わせ。区分ごとにサブトータルが出ます
- 予算にない実績は「予定外」と表示されます
- 予算バージョンを切り替えて、旧版基準の比較も可能

### 損益タブ

- **課全体の損益** = 売上高 −(加工費 + 外注費 + 期間費用)。利益率(損益 ÷ 売上高)も表示
- **案件別の損益** = 売上高 − 加工費 − 外注費。期間費用は課共通のため案件には配賦せず、
  **「期間費用(課共通)」行** として表示されます
- 案件別損益の合計 − 期間費用 = 課全体の損益(常に一致します)

## 5. よくある質問

**Q. 承認済みの予算を編集しようとするとエラーになる**
A. 仕様です。「3. 計画変更」の手順で改定版を作成してください。

**Q. 新しいドラフトが作成できない**
A. 同じ課・半期に策定中のドラフトが既にあります。先にそのドラフトを承認するか、内容を修正して使ってください。

**Q. 案件はどこで登録しますか**
A. 予算編集画面の「案件別の売上高・加工費・外注費」の表の下にある「**案件を追加**」から登録します。
案件を専用に管理する画面はありません(登録した案件は同じ課の実績入力・分析でも使えます)。

**Q. 課の売上高合計を直接入力したい**
A. できません。課の区分合計は常に案件明細の合計として算出されます。
案件ごとの詳細計画を登録してください。

**Q. 月別の内訳を入力したい**
A. 予算明細は半期一括の金額です。実績は同じ案件・費目に複数回計上できるため、
月ごとに分けて計上し、備考に「4月分」などと記録する運用ができます。

**Q. 数量や単価で入力したい**
A. 本システムは明細を金額のみで管理します。
人月×単価などの計算はメモ(備考)を活用してください。
