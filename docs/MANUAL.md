# 総合原価管理システム 操作マニュアル

このマニュアルでは、システムの基本的な業務フローを

1. **計画策定**(プロジェクト登録 → 売上予算・原価予算の作成と承認)
2. **実績入力**(売上実績・原価実績の計上)
3. **計画変更**(四半期改定などによる予算の改定)

の順に説明します。最後に分析画面(差異分析・損益)の見方をまとめます。

---

## 0. 事前準備

### 起動

```bash
# Docker の場合
docker compose up backend frontend

# ローカルに SDK がある場合
cd backend && dotnet run --project src/CostManagement.WebApi   # API (localhost:5100)
cd frontend && npm install && npm run dev                      # 画面 (localhost:5173)
```

ブラウザで `http://localhost:5173` を開くと「プロジェクト一覧」画面が表示されます。

### 基本の用語

| 用語 | 意味 |
|---|---|
| プロジェクト | 原価管理の単位(部門・事業・開発案件群など) |
| 品目 | 売上の内訳単位(案件名・サービス名など)。原価側の「売上対応品目」と対応する |
| 費目 | 原価の内訳単位(SE人件費・外注開発費など)。[README の費目マスタ](../README.md#管理できる費目費目マスタ)参照 |
| 売上対応品目 | 原価明細に付ける「どの売上(品目)のための原価か」の紐付け。空欄は共通費 |
| バージョン | 予算の版。承認すると編集不可になり、変更は改定版(新バージョン)として作成する |

### 予算のステータス

| 状態 | 意味 | できること |
|---|---|---|
| 策定中(Draft) | 編集中のドラフト | 明細の追加・修正・削除、承認 |
| 承認済(Approved) | 有効な予算。予実比較の既定の基準 | 参照、改定版の作成 |
| 失効(Superseded) | 新しい版の承認により失効した旧版 | 参照、バージョン比較、改定の引継ぎ元 |

## 1. 計画策定

### 1-1. プロジェクトを登録する

1. トップの「プロジェクト一覧」画面を開く
2. 「プロジェクト新規作成」フォームに **コード**(例: `SE-001`)、**名称**(例: 受託開発2026)、**会計年度** を入力
3. **[作成]** をクリック → 一覧に追加されるので、名称のリンクからプロジェクト詳細へ

> コードはシステム内で一意です。重複するとエラーになります。

### 1-2. 売上予算(当初)を策定する

先に売上予算を作ると、原価予算の「売上対応品目」の入力補完に品目名が出るため、
**売上予算 → 原価予算の順**で作るのがおすすめです。

1. プロジェクト詳細の「**売上予算バージョン**」カードで、予算名(例: `当初売上予算`)を入力し **[ドラフト作成]**
2. 売上予算編集画面で明細を登録する
   - **品目**: 案件名など(例: `案件A`)
   - **年月**: 計上予定月(例: 2026-04)
   - **金額**: 売上予定額(円)
   - 同じ品目・年月で再登録すると**上書き**されます
3. 明細をすべて登録したら **[この予算を承認する]** をクリック

### 1-3. 原価予算(当初)を策定する

1. プロジェクト詳細の「**原価予算バージョン**」カードで、予算名(例: `当初原価予算`)を入力し **[ドラフト作成]**
2. 原価予算編集画面で明細を登録する
   - **費目**: プルダウンから選択(SE人件費、外注開発費など)
   - **売上対応品目**: この原価がどの売上(品目)のためのものかを入力
     - 売上予算に登録済みの品目が入力候補に表示されます
     - **空欄にすると共通費**(特定の売上に対応しない原価。共通間接費など)になります
   - **年月・金額**: 発生予定月と金額(円)
   - 同じ費目・売上対応品目・年月で再登録すると**上書き**されます
3. **[この予算を承認する]** をクリック

> 承認のルール(売上・原価共通)
> - 明細が1件もない予算は承認できません
> - 承認すると編集できなくなります(変更は「3. 計画変更」の手順で改定版を作成)
> - 策定中のドラフトは同時に1つまでです。承認してから次の改定版を作成してください

## 2. 実績入力

実績は予算と独立して、発生の都度計上できます。
同じキー(品目・年月/費目・売上対応品目・年月)に**複数回計上でき、分析時に合算**されます。

### 2-1. 売上実績を計上する

1. プロジェクト詳細 → **[売上実績入力]**
2. フォームに入力して **[計上]**
   - **品目**: 売上予算と同じ品目名を入力(入力候補あり)。予算にない品目も計上でき、分析では「予定外」として表示されます
   - **年月・金額**: 計上月と金額(円)
   - **摘要**(任意): 「検収1回目」など

### 2-2. 原価実績を計上する

1. プロジェクト詳細 → **[原価実績入力]**
2. フォームに入力して **[計上]**
   - **費目**: プルダウンから選択
   - **売上対応品目**: 予算と同様、対応する売上の品目を入力(空欄 = 共通費)
   - **年月・金額・摘要**: 発生月と金額(円)、任意のメモ

> 品目別の損益を正しく出すには、予算・実績で**同じ品目名**を使ってください
> (表記ゆれは別品目として扱われます)。

### 2-3. 実績を訂正する

実績一覧の **[削除]** で取り消し、正しい内容で再計上してください。

## 3. 計画変更(予算の改定)

四半期の見直しなどで計画が変わったら、承認済み予算を直接編集するのではなく
**改定版(新バージョン)を作成**します。旧版は履歴として残ります。

### 3-1. 改定版を作成する

1. プロジェクト詳細の予算バージョンカード(原価・売上それぞれ)で、
   予算名に改定の名称(例: `第2四半期改定`)を入力
2. **引継ぎ元バージョン** を選択(既定は最新承認版。任意の旧版からも引き継げます)
3. **[ドラフト作成]** → 引継ぎ元の**明細をすべてコピーした**ドラフトが新バージョンとして作成されます

### 3-2. 明細を修正して承認する

1. 編集画面で、変更のある明細だけ登録し直す(同じキーで登録すると上書き)。不要な明細は削除
2. **[この予算を承認する]** をクリック
3. 承認と同時に、**旧承認版は自動的に「失効」**になります(データは残り、参照・比較できます)

### 3-3. 改定内容を確認する(バージョン比較)

1. プロジェクト詳細 → **[予算バージョン比較]**
2. タブで **原価予算/売上予算** を選び、**基準バージョン**と**比較バージョン**を選択
3. 明細単位の増減と合計の増減が表示されます(例: 当初予算 vs 第2四半期改定)

> 差異分析は既定で「最新の承認済み予算」を基準にしますが、分析画面のバージョン選択で
> 旧版(当初予算など)を基準にした予実比較もできます。

## 4. 分析画面の見方

プロジェクト詳細 → **[予実差異分析・損益]**。3つのタブがあります。
いずれも期間(自/至)で対象月を絞り込めます。

### 原価差異タブ

- 差異 = **実績金額 − 予算金額**。**正の値(赤)= 予算超過 = 不利差異**、負の値(緑)= 有利差異
- 明細は「費目 × 売上対応品目 × 年月」の粒度で突き合わせ
- 予算にない実績は「予定外」と表示されます
- 予算バージョンを切り替えて、旧版基準の比較も可能

### 売上差異タブ

- 差異の符号は原価と逆で、**正の値(緑)= 売上超過 = 有利差異**、負の値(赤)= 未達
- 明細は「品目 × 年月」の粒度

### 損益(粗利)タブ

- 最新の承認済み売上予算・原価予算を突き合わせ、**粗利(売上 − 原価)の予実**を表示
- **品目別損益**: 売上の品目と原価の「売上対応品目」を突き合わせた案件単位の粗利。
  売上対応品目のない原価は **「(共通)」行** に集計されます。品目別の合計は全体と常に一致します
- 粗利率(粗利 ÷ 売上)と月別内訳も表示されます

## 5. よくある質問

**Q. 承認済みの予算を編集しようとするとエラーになる**
A. 仕様です。「3. 計画変更」の手順で改定版を作成してください。

**Q. 新しいドラフトが作成できない**
A. 策定中のドラフトが既にあります。先にそのドラフトを承認するか、内容を修正して使ってください。

**Q. 品目別損益で原価が「(共通)」に入ってしまう**
A. 原価明細の「売上対応品目」が空欄か、売上側の品目名と一致していません。
該当明細を正しい品目名で登録し直してください(実績は削除→再計上)。

**Q. 数量や単価で入力したい**
A. 本システムは SE 費用管理を想定し、明細は金額のみで管理します。
人月×単価などの計算はメモ(摘要)を活用してください。
