# ADR-0012: フロントは自前 SVG 描画・エラーは固定トースト通知

- 状態: Accepted
- 日付: 2026-07(トーストは Issue #4)

## 背景

差異・損益のダッシュボードで簡単な図表(棒グラフ等)が必要だが、チャートライブラリを導入すると
依存とバンドルサイズが増える。また、エラー表示が画面内に散在すると気づきにくいという課題があった。

## 決定

- 図表は**手書きの SVG** で描画し、外部チャートライブラリを導入しない。
- エラーは**画面右下の固定トースト**で通知し、一定時間(約6秒)で自動的に消える(`role=alert`)。
- ダイアログ(月次入力など)は汎用 `Modal` コンポーネント(`role=dialog` / `aria-modal`、Esc・背景クリックで閉止)で表す。
- 金額入力は 3 桁カンマ区切り表示の共通 `MoneyInput` コンポーネントに統一する。

## 結果

- 依存が少なく軽量で、描画を要件に合わせて完全に制御できる。
- 複雑な対話的チャート(ズーム・凡例トグル等)は自前実装が必要になる(現状の要件では不要)。
- エラーの視認性が上がり、画面レイアウトを乱さない。
