# ADR-0003: 明細は金額のみとし数量 × 単価を採用しない

- 状態: Accepted
- 日付: 2026-07 頃

## 背景

原価の明細を「数量 × 単価」で積算する方式も検討しうるが、本システムの利用者が扱うのは
案件別・費目別の**金額計画**であり、人月や工数の積算は運用上メモ(備考)で足りていた。
数量 × 単価を導入すると、価格差異/数量差異の分解や単価マスタなど、要件外の複雑性を抱え込む。

## 決定

- 明細(予算・実績)は**金額のみ**で管理する。数量・単価の項目を持たない。
- 差異は **差異 = 実績金額 − 予算金額** の単純な符号付き差分とし、価格差異/数量差異の分解は行わない。
- 人月 × 単価などの計算が必要な場合は実績の備考で補う。

## 結果

- モデルと UI が単純になり、金額計画にフォーカスできる。
- 単価変動と数量変動を分けた分析はできない(要件外なので許容)。
- **数量 × 単価は復活させない**(過去に導入していた項目は撤去済み)。
