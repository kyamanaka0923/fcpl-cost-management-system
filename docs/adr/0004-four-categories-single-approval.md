# ADR-0004: 4区分を1予算としてまとめて承認する

- 状態: Accepted
- 日付: 2026-07-11

## 背景

旧世代では売上計画と原価計画を別集約として独立に承認していた。しかし課の半期予算は
**売上高・加工費・外注費・期間費用**が一体で意思決定される。別々の承認は、
どの版の売上とどの版の原価が対応するのかが曖昧になり、損益の突き合わせを難しくしていた。

## 決定

- 1つの `DepartmentBudget` が**売上高・加工費・外注費・期間費用の4区分**をまとめて持ち、
  **1回の承認**で確定する。
- 売上と原価を別集約・別承認にする方式は採らない。

## 結果

- 損益(売上 − 総コスト)が単一の版の中で常に整合する。
- 4区分のいずれかだけを部分承認することはできない(一体承認が要件なので許容)。
- **売上と原価の別集約・別承認は復活させない**。
