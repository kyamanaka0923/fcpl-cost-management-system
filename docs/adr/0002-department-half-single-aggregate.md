# ADR-0002: 予算の管理単位を「課 × 半期」の単一集約にする

- 状態: Accepted
- 日付: 2026-07-11(要件変更)
- 関連: [requests/2026-07-11-requirement-change.md](../requests/2026-07-11-requirement-change.md)

## 背景

初期実装ではプロジェクト単位が予算策定の起点だった。しかし実際の原価管理は
**課(部門)単位**で行われ、策定期間は**年度の上期/下期(半期)**だった。管理単位が業務実態と合っていなかった。

## 決定

- 予算の管理単位を **課(Department) × 半期(FiscalHalf: yyyy-H1/H2)** とする。
- 予算は**単一集約 `DepartmentBudget`**(集約ルート)として表現し、(課, 半期)ごとにバージョン管理する。
- プロジェクトは予算策定の起点から**明細の内訳次元「案件」**へ降格する(ADR-0008)。
- バージョンは v1(当初)→ 改定(明細コピーで新版)。状態は Draft → Approved → Superseded。
  承認済みは編集不可。ドラフトは同一(課, 半期)に1件。承認時に旧承認版を Supersede する。

## 結果

- 予算・実績・分析・画面のほぼ全層を再構築する大規模変更となった(リネームでは済まなかった)。
- 業務実態に一致し、以降の要件(部集計・粗利率・月次入力)を自然に積み増せた。
- 旧世代データは移行せず作り直す方針とした(ADR-0007。「プロジェクト → 課」は機械的対応が不能なため)。
- **この単位は復活・分割しない**(プロジェクト単位予算に戻さない)。
