## ルール(デシジョンテーブル: 期間費用の明細を入力するとき)

| 同じ費目に既にあるもの | 入力する明細 | 結果 |
|---|---|---|
| なし | 費目一括(明細名なし) | 受け付ける |
| なし | 明細名あり | 受け付ける |
| 費目一括 | 費目一括 | 上書きする |
| 費目一括 | 明細名あり | 拒否: この費目は費目一括で入力されています。明細を使うには先に費目一括の金額を削除してください。 |
| 明細名あり | 費目一括 | 拒否: この費目には明細があります。費目一括の金額ではなく明細で入力してください。 |
| 明細名あり | 同じ明細名 | 上書きする |
| 明細名あり | 別の明細名 | 受け付ける |

```
費目の合計 = Σ その費目の明細の金額
```

- 明細名は後から変えられる。金額と月次はそのまま残る。同じ費目に同じ明細名が既にあれば拒否する
- 実績も明細名を任意で持てる。計画にない明細名の実績は「予定外」(BR-ACT-001)

## 例

- ライセンス費 → AWS 300,000 と GitHub 200,000 → ライセンス費の合計 500,000
