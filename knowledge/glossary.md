# 用語集

出どころ: SRC-REQ(§2 用語定義)、SRC-ADR-0002〜0013。コード上の名前を括弧で併記する。

| 用語 | 定義 | 関係する業務ルール |
|---|---|---|
| 部(Division) | 課の上位組織。配下の課の予実を合計する集計単位。**部自体は予算を策定しない** | BR-ORG-001、BR-DIV-001 |
| 課(Department) | 予算策定の管理単位(部門)。必ず 1 つの部に属する | BR-ORG-001 |
| 半期(FiscalHalf) | 予算の策定単位。年度の上期(4〜9 月)/ 下期(10〜3 月)。表記は `yyyy-H1` / `yyyy-H2` | BR-FH-001 |
| 月インデックス | 半期の中の月の位置(1..6)。上期は 1=4 月 … 6=9 月、下期は 1=10 月 … 6=3 月 | BR-FH-001 |
| 案件(Project) | 課に属する、売上・コストの内訳の単位。マスタとして登録し、内部の識別子は GUID。コードは課の中で一意 | BR-BUD-003 |
| 費目(CostElement) | 期間費用の内訳の単位(人件費・ライセンス費など)。**システム全体で共通のマスタ** | BR-BUD-003 |
| 区分(BudgetCategory) | 予算の構成要素。売上高・加工費・外注費(案件別)と、期間費用(費目別)の 4 つ | BR-BUD-001、BR-BUD-003 |
| 予算(DepartmentBudget) | 課 × 半期の予算。4 区分の明細を持ち、まとめて 1 回で承認する | BR-BUD-001 |
| 金額 | 円で表す値。0 以上の 1 円単位の整数(1 円未満の端数を含まない)。予算の明細の半期一括の金額・月別金額、実績の計上金額に共通 | BR-BUD-007 |
| 明細(BudgetLine) | 区分 × 案件、または 期間費用 × 費目(× 明細名)の金額。半期一括か月次(1..6)で入力する | BR-BUD-003〜007 |
| 明細名(PeriodDetail) | 期間費用の費目の中をさらに分ける自由入力の名前(例: ライセンス費 → AWS / GitHub) | BR-BUD-006 |
| 費目一括 | 明細名を持たない期間費用の明細。同じ費目で明細名ありの明細とは併用できない | BR-BUD-006 |
| 半期一括 / 月次 | 明細の金額の入力のしかた。月次にした明細の半期の金額は、月別金額の合計になる | BR-BUD-005 |
| バージョン | 予算の版。当初(v1)→ 改定(v2…) | BR-BUD-002 |
| 課承認 | 課がその半期の予算を確定する承認(Draft → Approved) | BR-BUD-002 |
| 改定 | 承認済みの予算から、明細を引き継いだ新しいバージョンのドラフトを起こすこと | BR-BUD-002 |
| 失効(Superseded) | 改定版が承認されたことで、旧い承認版が置き換えられた状態。履歴として残る | BR-BUD-002 |
| 部承認 | 部長が配下の課の予算をまとめて確定する承認。課承認とは独立し、取り消せる | BR-DIV-001 |
| 実績(ActualEntry) | 課 × 半期に計上した実際の金額。同じキーに何度でも計上でき、分析で合算する | BR-ACT-001 |
| 予定外 | 予算に対応する明細がない実績 | BR-ACT-001、BR-VAR-001 |
| 差異 | 実績金額 − 予算金額(符号付き) | BR-VAR-001 |
| 計画損益 / 損益 | 売上高 −(加工費 + 外注費 + 期間費用) | BR-PL-001 |
| 粗利率 | 損益 ÷ 売上高。売上高が 0 のときは表示しない | BR-PL-001 |
| 未策定 | 承認済みの予算がない課。部の集計では内訳に出し、部合計には含めない | BR-DIV-001 |
