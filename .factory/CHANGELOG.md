# 工場の変更履歴

工場(指示・エージェント・スキル・CI・フック・ナレッジの型)の版と、変更の種類。
`.claude/`・`AGENTS.md`・`.github/workflows/`・`tools/factory/` を変えたら、ここに 1 行足し、必要なら `VERSION` を上げる
(フェーズ4 の CI `factory-version` が検査する)。

## 変更の種類(導入計画 §11.2)

| 種類 | 中身 | 仕掛かり品(流れている作業項目)の扱い | 版 |
|---|---|---|---|
| A | 軽微な改善(言い回し・誤検知の修正) | そのまま続行 | 上げない(CHANGELOG に書くだけ) |
| B | 検査の強化(新しい CI・より厳しい判定) | 警告で入れ、仕掛かり品が流れ切ってから必須にする | `factory-vN` の N を上げる |
| C | 工程・成果物の形の変更 | 流し切るか、やり直すかを PR で決める | N を上げる |
| D | ナレッジの訂正 | マージ済みの成果物まで遡って直す | 上げない(`knowledge/` の変更として扱う) |
